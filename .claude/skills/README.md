# Assistant guides

Project guides live here as the canonical copy. Read them only when relevant to the task. Their instructions supplement the maintainer's current request.

- `ngu-verify` describes how to select and report checks.
- `ngu-devmode` describes scripted interaction with the engine.
- `nguidle-port` points to the platform integration guides.
- `ponytail`, `ponytail-review`, `ponytail-audit`, `ponytail-debt`, `rust-patterns` and `rust-testing` are third-party guidance. Their source, licenses and normalized content hashes are recorded in `skills.lock`. Their contents match the revisions recorded in the lock file. Verify technical claims against the relevant implementation or official reference.

Other assistants may read these same files directly. User-installed plugins and hooks are optional and can add instructions outside this repository.
