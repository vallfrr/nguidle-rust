(`__ENGINE_TAG__`). This repository was generated by `just new-port` from the engine's port template; it

## First steps
1. Read `docs/PORTING.md` in the engine repository: it is the complete guide, with a checklist for "my port is finished".
2. `just check` — must pass before and after every change.
3. Prepare your game data (engine guide, "Prepare the data"), then `just run <prepared folder> <throw-away profile folder>`.
4. Replace the `PORT:` stand-ins one at a time, keeping `tests/contract.rs` green.

See `AGENTS.md` if an AI assistant helps you.
