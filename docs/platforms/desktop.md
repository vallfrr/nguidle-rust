# Desktop

The Windows host is built from the engine repository using the verified original installation. See the [player setup](../../README.md) and [contributor guide](../../CONTRIBUTING.md). The desktop GPU window supports resizing, fullscreen and controller focus. [Console mode](../CONSOLE-MODE.md) records its interaction model and outstanding physical checks.

The generated game and interpreter use shared runtime components. See [fidelity](../FIDELITY.md) for comparison limits.
