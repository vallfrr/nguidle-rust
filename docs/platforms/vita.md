# PS Vita

The separate [Vita repository](https://github.com/vallfrr/nguidle-vita) builds the VitaSDK host against a pinned engine revision. See its README for preparation, build and hardware setup.

The host uses a logic thread and a rendering thread. The hardware target is 960 by 544. [Vita implementation and measurements](../VITA.md) and [performance notes](../VITA-60.md) document the scope and limitations of earlier runs. A build passing package checks does not measure performance on the console.
